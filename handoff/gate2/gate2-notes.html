• Motion cannot be shown in a still. Each landing section lists what moves, with which duration and easing tokens, and what happens under reduced motion. The captures were taken with reduced motion on, which is also the resting state of each page.
  • The editor is real. One request form exists in JavaScript, React, Vue and Angular, in Arabic and English, and runs from the published packages in a sandboxed frame. Edit and re-run work in all four frameworks. The status bar names the package and version that is running.
  • The prototypes are client-rendered on unpatched 0.2.1. They avoid prerendering, which 0.2.1 cannot do for eight components. They follow the honest-render rule: own CSS only places, spaces and animates with tokens, and where the packages lack something they use plain HTML and record a gap.
  • Gaps every prototype ran into: no code block component; no compact header controls for language, direction and mode; the portal header's skip link breaks under a base href; the portal footer always renders a support section with an Arabic default name; four-option segmented controls wrap at phone width; field hints render at 10 px; and the icon set has no copy, download, reset, sun, moon or language icons, so those actions are text buttons.
