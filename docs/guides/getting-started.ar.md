# البدء

تُستخدم هوية بأربع طرق: بلغة JavaScript المجرّدة عبر `@hawiyah/styles` و`@hawiyah/vanilla`، أو بمحوّل React أو Vue أو Angular. وتشترك الطرق كلها في ورقة أنماط واحدة، ويوفّر التطبيق اللغة والاتجاه والنصوص كلها.

## الحزم والإصدارات

تحتاج كل طريقة إلى حزمتين: `@hawiyah/styles` التي تضمّ ورقة الأنماط، ومحوّل واحد.

جدول: حزم كل طريقة من طرق الاستخدام

| الطريقة | حزمة المحوّل | الاعتماديات النظيرة |
| --- | --- | --- |
| JavaScript المجرّدة | `@hawiyah/vanilla` | لا شيء. |
| محوّل React | `@hawiyah/react` | React 19 وReact DOM 19. |
| محوّل Vue | `@hawiyah/vue` | Vue 3.5 أو إصدار لاحق من الفرع 3.x. |
| محوّل Angular | `@hawiyah/angular` | Angular 22 (`@angular/common` و`@angular/core` و`@angular/forms`) وRxJS 7.8 أو إصدار لاحق من الفرع 7.x. |

تشترك الحزم السبع في إصدار واحد، والإصدار الحالي هو 0.3.0. وهو منشور تحت وسم التوزيع next، فالأمر الذي لا يذكر إصدارًا ولا وسمًا يثبّت الإصدار الذي يشير إليه وسم التوزيع latest، وهو إصدار أقدم. وأمر التثبيت المطبوع في ملفات README للحزم لا يذكر إصدارًا، فيثبّت ذلك الإصدار الأقدم. ثبّت الحزمتين بمدير الحزم الذي يستخدمه المشروع، بالإصدار الدقيق 0.3.0 مكتوبًا بعد اسم كل حزمة؛ ولا يُستخدم وسم توزيع، لأن الوسم next ينتقل إلى الإصدار التالي. ويولّد قسم التثبيت في الصفحة الرئيسية للدليل أمر كل مدير حزم من الإصدار المقيَّد، ولا تكرّره هذه الصفحة.

والحزم إصدارات سابقة للإصدار 1.0، فقد يغيّر إصدار فرعي واجهةً برمجية. ويعتمد كل محوّل على `@hawiyah/core` بالإصدار نفسه، فيُثبَّت مع تثبيت المحوّل؛ ولا تثبّته مباشرة إلا عندما تستورد شيفرة التطبيق دواله المساعدة.

## ورقة الأنماط

تُستورد ورقة الأنماط مرة واحدة، عند نقطة دخول التطبيق. وهي ملف واحد مسطّح، ولا يستوردها شيء ضمنيًا. أما إعادة الضبط والخطوط التي تسمّيها رموز التصميم فملفات منفصلة يختار التطبيق استيرادها: يحمّل `@hawiyah/styles/fonts.css` الخطوط، وليس جزءًا من ورقة الأنماط أبدًا.

```js title="src/main.js"
import '@hawiyah/styles/styles.css';
import { enhance } from '@hawiyah/vanilla';

enhance(document.querySelector('#application'));
```

تُرقّي الدالة `enhance()` من `@hawiyah/vanilla` الترميز الدلالي داخل العنصر الذي تتلقاه، وتعيد دالةً تلغي هذه الترقية؛ والتطبيق الذي يزيل الشجرة الفرعية يستدعي تلك الدالة أولًا. ويفترض مسار JavaScript وجود أداة تجميع، مثل Vite، تحلّ استيراد الحزم. ويمكن للصفحة التي لا تستخدم أداة تجميع أن تربط ورقة الأنماط المبنية من `@hawiyah/styles` مباشرة، ويُقدَّم المجلد الذي يضمّها كما هو مع مجلد الأصول، لأن الإشارة إلى الخطوط والأيقونات نسبية إلى موقعها.

```tsx title="src/main.tsx"
import '@hawiyah/styles/styles.css';
import { Button } from '@hawiyah/react';
```

```ts title="src/main.ts"
import { createApp } from 'vue';
import App from './App.vue';
import '@hawiyah/styles/styles.css';

createApp(App).mount('#app');
```

ويحمّل تطبيق Angular ورقة الأنماط مرة واحدة في الملف src/styles.css بقاعدة استيراد للمسار `@hawiyah/styles/styles.css`، ويستورد المكوّنات والموجّهات المستقلة التي يستخدمها من `@hawiyah/angular`، مثل `HwButtonDirective`. وتعرض ملفات README للحزم الاستيراد في مكوّن مثال ولا تسمّي نقطة دخول، ولا يسمّي ملف README الخاص بمحوّل Angular أي ملف؛ فالملفات المذكورة في هذا القسم هي الموضع الذي اختاره الدليل، ويصلح أي موضع يحمّل ورقة الأنماط مرة واحدة.

## اللغة والاتجاه

يضبط التطبيق الخاصيتين `lang` و`dir` على المستند أو على شجرة فرعية، وهما مستقلتان: فقد تحتوي صفحة بالإنجليزية على منطقة بالعربية، والعكس. ولا تقرأ الحزم لغة المستند أبدًا لتختار النص أو الاتجاه.

```html title="index.html"
<html lang="en" dir="ltr">
  <body>
    <div id="application">…</div>
    <section lang="ar" dir="rtl">…</section>
  </body>
</html>
```

تستخدم الأنماط المضمّنة في الحزم خصائص CSS المنطقية، فيتبع المكوّن الاتجاه المحسوب للعنصر الذي يقع فيه. وعندما يعرف التطبيق اتجاه القراءة مسبقًا، يكتب قيمة صريحة للخاصية `dir`، لأن محرّكات المتصفحات التي لا تدعم النطاقات في CSS تطبّق الهندسة الزخرفية للحدّ ذي الاتجاه التلقائي في اتجاه القراءة من اليسار إلى اليمين. والسمة ووضع الألوان والكثافة هي الخصائص `data-hw-theme` و`data-hw-mode` و`data-hw-density` على عنصر سلف، ولا تتوقف على اللغة.

## إعادة الضبط

إعادة الضبط اختيارية. فلا تطبّق `@hawiyah/styles/styles.css` إعادة ضبط عامة؛ والتطبيق الجديد الذي يتولّى أنماطه الأساسية بنفسه يستورد `@hawiyah/styles/reset.css` أيضًا، في الموضع نفسه.

```js title="src/main.js"
import '@hawiyah/styles/styles.css';
// Optional, only when the application wants the reset:
import '@hawiyah/styles/reset.css';
```

## النصوص من التطبيق

لا تحتوي الحزم على نصوص مدمجة ولا ترجمات ولا إعدادات محلية افتراضية. وكل كلمة يضعها المكوّن على عناصره، مثل الأسماء الميسّرة وتسميات عناصر التحكم الداخلية والعناوين ورسائل الحالة أو التحقق، هي خاصية مكوّن أو مُدخل أو خيار أو خاصية HTML يكتبها التطبيق. أما المحتوى الأساسي، مثل تسمية الزر، فهو محتوى العنصر أو البيانات.

والنص الذي لا يُحتاج إليه إلا مع ميزة ما مطلوبٌ مع تلك الميزة. والنص الذي يتوقف على البيانات دالةٌ في المحوّلات يبدأ اسمها بالبادئة get وينتهي باللاحقة Label أو Message، تتلقى البيانات وتعيد السلسلة النصية كاملة؛ ولا يضيف المكوّن إليها كلمات ولا علامات ترقيم. والمكوّن الذي ينسّق تاريخًا أو رقمًا، أو يرتّب نصوصًا، يأخذ الإعدادات المحلية من التطبيق، ولا يرجع إلى الإعدادات المحلية للمتصفح.

في `@hawiyah/vanilla` يُقرأ النص أولًا من الترميز الذي يكتبه المطوّر، ثم من خيار المتحكم، ثم من خاصية `data-hw-*` على جذر المتحكم. ويُقرأ ما يقابل الدالة في المحوّلات من خاصية في القالب لا يحمل اسمها البادئة get، مثل `data-hw-page-label` لدالة تسمية الصفحة، وتحلّ ثلاثة خيارات محلّ الاسم الداخلي المكتوب في الترميز عندما تُمرَّر صراحةً: تسمية زر المسح في `createSearchField`، وتسمية زر الإظهار في `createPasswordField`، وتسمية العلامة في `createPortalHeader`. وعندما يغيب نص مطلوب، لا يعرض المكوّن شيئًا مكانه، ويصدر تحذيرًا مرة واحدة أثناء التطوير.

## مثال

المثال [زر](../components/button.md) بتسمية ظاهرة، مكتوب بكل طريقة من الطرق الأربع. وتسمّي التسميةُ الإجراء. ويكتب مقطع `html` الخاصية `type="button"`، لأن النوع الافتراضي للزر داخل نموذج في المتصفح هو submit؛ ويكتب `Button` و`hwButton` النوع `button` ما لم يُكتب نوع آخر.

```html live example=continue
<button class="hw-button" type="button" data-variant="primary" data-size="md">متابعة</button>
```

```tsx live example=continue
<Button variant="primary">متابعة</Button>
```

```vue live example=continue
<Button variant="primary">متابعة</Button>
```

```ts live example=continue framework=angular
template: `<button hwButton variant="primary">متابعة</button>`
```

والنتائج الأربع هي العنصر نفسه. ولا يحتاج مقطع `html` إلى برنامج نصي، لأن الزر الأصلي يعمل دون `@hawiyah/vanilla`؛ وتلزم `enhance()` للمكوّنات التي لها متحكم. وتملك React وVue وAngular عناصرها وتعرض الزر بنفسها، ولا يُركَّب متحكم vanilla في أشجارها. وتذكر صفحات المكوّنات الواجهة البرمجية الكاملة لكل مكوّن، بدءًا بصفحة [زر](../components/button.md).
