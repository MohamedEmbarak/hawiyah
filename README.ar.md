# هوية — Hawiyah

**مكتبة مكوّنات واجهات مستخدم مبنية للامتثال لكود المنصات الصادر عن هيئة الحكومة الرقمية.** توفّر هوية رموز التصميم والأنماط والمكوّنات القابلة للوصول لأطر العمل JavaScript، React، Vue، Angular، مع دعم كامل للعربية والإنجليزية وقوالب صفحات لرحلات خدمات متكاملة.

تم التطوير بواسطة فريق التطوير في قطاع المنصات الوطنية - مركز المعلومات الوطني

Developed by the Development Team in the National Platforms Sector — National Information Center.

[الدليل التفاعلي](https://mohamedembarak.github.io/hawiyah/) · [المستودع](https://github.com/MohamedEmbarak/hawiyah) · [English](README.md) · [نطاق التغطية](docs/coverage.md) · [البنية](docs/architecture.md) · [دليل التوسعة](docs/extension.md) · [سجل التحقق](docs/validation.md) · [دليل المساعدات البرمجية](llms.txt)

تستخدم الواجهة افتراضيًا أساس DGA المربوط بلقطات المصدر المزوّدة من كود المنصات. وتحتفظ سمة **Signature** (التوقيع) الاختيارية (`data-hw-theme="hawiyah"`) بالأخضر المزرق والعاجي الدافئ. شعار هوية هو كلمة **هوية** العربية باللون الأساسي لكود المنصات. تستخدم كتابة الشعار **Aref Ruqaa Bold محوّلًا إلى مسارات SVG**، فلا يحتاج عرضه إلى تحميل الخط. تبقى خطوط الواجهات IBM Plex Sans Arabic وIBM Plex Sans. يتضمن [دليل الهوية المحلي](brand/index.html) و[إرشادات الشعار](brand/README.md) و[حزمة الهوية ZIP](brand/hawiyah-brand-kit.zip) الشعار ومؤشرات تحميل تحرّك حروفه بخلفية شفافة.

معاينات: [المحرّر المباشر بالعربية](docs/previews/component-editor-ar-dark.png)، و[المعرض بالعربية على الهاتف](docs/previews/playground-ar-mobile.png)، و[استوديو التخطيط](docs/previews/layouts.png)، و[منتقي التاريخ الميلادي وأم القرى](docs/previews/date-picker.png).

تطبّق هوية **كود المنصات — Platforms Code** الصادر عن **هيئة الحكومة الرقمية — DGA**، وهو **نظام التصميم الموحد — Unified Design System** في **المملكة العربية السعودية — Kingdom of Saudi Arabia (KSA)**، في الأسس والمكوّنات وأنماط الخدمات. **يُوثَّق الامتثال متطلبًا متطلبًا، مع أدلة الاختبار والبنود المفتوحة.** تُطوَّر هوية بشكل مستقل، وليست منتجًا رسميًا للهيئة. راجع [توثيق المواءمة](docs/alignment.md) قبل وصف أي منتج بأنه متوافق. يسجل [مرجع DGA ودليل الانتقال](docs/dga-reference.md) لقطات المصدر المزوّدة بتاريخ 2026-10-29، والقيم الدلالية للوضعين الفاتح والداكن، ومعرّفات العناصر والفجوات. تاريخ التصدير ليس رقم إصدار رسميًا. فُكّ ترميز الملفات المحلية الـ23 جميعها، بما فيها الملفات الستة التي تعذّر نقلها سابقًا، ولم تُزوَّد مكتبة مستقلة لمكونات الويب. يوضح [جرد المصادر](docs/dga-source-inventory.md) و[متابعة التدقيق](docs/dga-audit-followup.md) الأدلة والفجوات المتبقية. قالب الحج خاص بتطبيق الحج وخارج نطاق هوية.

استكشف [معرض القوالب](https://mohamedembarak.github.io/hawiyah/#templates) و[صفحة الخدمة بعرض كامل](https://mohamedembarak.github.io/hawiyah/?preview=template#templates/service) و[نموذج الطلب](https://mohamedembarak.github.io/hawiyah/?preview=template#templates/form). الأمثلة ثنائية اللغة وتعمل ببيانات تجريبية محلية؛ اربطها بخدمات تطبيقك عند استخدامها فعليًا.

يتضمن المعرض أيضًا [الصفحة الرئيسية](https://mohamedembarak.github.io/hawiyah/?preview=template#templates/home) و[صفحة البحث](https://mohamedembarak.github.io/hawiyah/?preview=template#templates/search)، مع حفظ عبارة البحث والتصفية وإزالة الاختيارات والترتيب والتنقل بين النتائج. توثّق أدلة `PORTAL.md` في حزم الأطر استخدام `PortalLayout` و`SecondaryNav` لإضافة هيكل البوابة مباشرة.

## حالة التطوير

المشروع متاح المصدر في **مرحلة تطوير 0.2** بترخيص Apache 2.0. تدعم الحزم السبع **فهرسًا من 83 مكونًا** عبر vanilla وReact وVue وAngular، يشمل النماذج والتفاعل والمحتوى وأنماط الخدمات السعودية و12 مكونًا للتخطيط. نُشر الإصدار 0.2.1 على npm تحت النطاق `@hawiyah` إصدارًا سابقًا للإصدار 1.0، لذا قد تتغير الواجهات البرمجية بين الإصدارات الفرعية. ولا يعني النشر أو وجود شفرة أو مثال يعمل اكتمال الجاهزية للإنتاج.

تفصل [خريطة الطريق](docs/roadmap.md) بين المخطط والمنفذ والمتحقق منه. يعرض [components.json](components.json) هذه الحالات أيضًا بصيغة قابلة للقراءة آليًا. تُراجع تغطية كل إطار عمل والتحقق الفعلي من الفهرس، ولا تُستنتج من أسماء الحزم.

يفتح الدليل بالعربية، مع حفظ اختيار الإنجليزية وإتاحة البحث باختصار Ctrl/Cmd + K. تتضمن صفحة كل مكوّن تبويبات للمعاينة والشفرة والتجربة الحية، مع محررات HTML وCSS وJavaScript، ونتيجة تفاعلية معزولة، وسجل للأخطاء، وإعادة ضبط المثال. تستخدم مساحة التجربة تطبيق المكوّن بلغة جافاسكريبت دون إطار عمل؛ وتبقى إرشادات الأطر وواجهاتها البرمجية في مقالاتها المخصصة. لا تدعم المعاينة المضمّنة استيراد المكتبات الخارجية. ترافق الدليل المنشور [تراخيص مكتبات المحرر](https://mohamedembarak.github.io/hawiyah/licenses/editor.txt).

## اتجاه النظام

- أساس DGA افتراضي موثق بالمصدر، وسمة هوية اختيارية، وإمكان إنشاء سمات مخصصة.
- مكونات بلا نصوص مدمجة: يزوّد التطبيق كل تسمية ورسالة واسم يُقرأ بالتقنيات المساعدة، بالعربية أو الإنجليزية أو أي لغة أخرى، ويزوّد كذلك اللغة المحلية (locale) المستخدمة في التنسيق. يبقى اتجاه العرض مستقلًا عن اللغة، وتدعم خصائص CSS المنطقية الاتجاهين RTL وLTR.
- مكونات بواجهات برمجية طبيعية لكل إطار، تشترك في قيم التصميم والتنسيق ومنطق التفاعل.
- HTML وCSS قابلان للاستخدام دون JavaScript حيث تسمح طبيعة المكون، مع تفعيل واضح للسلوك التفاعلي.
- مكونات أساسية، وكتل قابلة للتحرير، وأمثلة لرحلات اكتشاف الخدمة وتقديم الطلب ومراجعته وإدارته.
- مختبر لأنواع إدخال HTML الأصلية الـ22، وأنماط البيانات السعودية، وتركيب التخطيطات المتجاوبة.
- تقويم ومنتقي تاريخ للميلادي وأم القرى، بقيم تاريخ مستقلة عن الوقت ومرجع بيانات موثق.
- نقاط توسعة موثقة، وشفرة مفهومة، وأنواع واضحة تساعد التطوير اليدوي والتطوير بمساعدة الذكاء الاصطناعي.

## الحزم

| الحزمة | المسؤولية |
|---|---|
| `@hawiyah/tokens` | قيم التصميم والمتغيرات الدلالية للسمات |
| `@hawiyah/styles` | تنسيقات المكونات وأدوات التخطيط وملف reset اختياري |
| `@hawiyah/core` | منطق مشترك مستقل عن الأطر، وفحص النصوص المطلوبة، وأدوات تنسيق تأخذ اللغة المحلية من التطبيق |
| `@hawiyah/vanilla` | متحكمات تضيف التفاعل إلى HTML مع إتاحة إزالة التفعيل |
| `@hawiyah/react` | مكونات React تستخدم الأساس المشترك |
| `@hawiyah/vue` | مكونات Vue تستخدم الأساس المشترك |
| `@hawiyah/angular` | مكونات Angular تستخدم الأساس المشترك |

ثبّت التنسيقات ومحوّلًا واحدًا بالأمر `npm install @hawiyah/styles @hawiyah/react`، مع استبدال `react` بـ `vanilla` أو `vue` أو `angular`. تبقى ملفات الحزم في المصدر موسومة بـ `private: true`، ولا ينشر الأمر `pnpm release:packages` إلا الأرشيفات التي تحقق منها `pnpm check:packages`. ترتبط كل حزمة إطار بتبعياتها، ولا يعتمد المنطق المشترك على بيئة تشغيل أي إطار.

## التشغيل محليًا

من مجلد المشروع، استخدم إصدار pnpm المحدد في `package.json`. أُجريت فحوص التطوير باستخدام Node.js `24.19.0` وpnpm `11.25.0`:

```sh
git clone https://github.com/MohamedEmbarak/hawiyah.git
cd hawiyah
pnpm install
pnpm build:packages
pnpm dev
```

تبدأ بيئة التطوير بمعرض vanilla. افتح `#components` لفهرس المكونات، و`#inputs` لدلالات الإدخال، و`#layouts` لتركيب التخطيطات. يتضمن المعرض دليل الهوية المحلي. لتشغيل مثال إطار بعد بناء الحزم:

```sh
pnpm --filter @hawiyah/example-react dev
pnpm --filter @hawiyah/example-vue dev
pnpm --filter @hawiyah/example-angular dev
```

اختر المثال المطلوب؛ كل أمر يشغّل خادم تطوير مستقلًا. تشمل الفحوص `pnpm build` و`pnpm typecheck:playground` و`pnpm test` و`pnpm test:browser` و`pnpm check:packages`. تُوثَّق النتائج وإعداد المتصفح في [سجل التحقق](docs/validation.md). أدلة الواجهات البرمجية: [vanilla](packages/vanilla/README.md)، و[React](packages/react/README.md)، و[Vue](packages/vue/README.md)، و[Angular](packages/angular/README.md).

## مثال HTML

```html
<section lang="ar" dir="rtl" data-hw-theme="dga"
         data-hw-mode="light" data-hw-density="comfortable">
  <div class="hw-card">
    <div class="hw-card-body">
      <h2>طلب جديد</h2>
      <p>راجع متطلبات الخدمة قبل البدء.</p>
      <button class="hw-button" data-variant="primary" type="button">
        ابدأ الطلب
      </button>
    </div>
  </div>
</section>
```

تُحمَّل التنسيقات في التطبيق المستهلك:

```ts
import '@hawiyah/styles/styles.css';
```

ملف `styles.css` ملف واحد مسطّح يتضمن رموز التصميم، فيمكن أيضًا ربطه مباشرة في الصفحة دون أداة تجميع. ملف `@hawiyah/styles/reset.css` اختياري، ويُحمَّل قبل تنسيقات المكونات عند الحاجة. يوثق [عقد التفاعل](packages/core/API.md) و[دليل توسعة vanilla](packages/vanilla/EXPANSION-API.md) بنية HTML وواجهات التفعيل. يتولى كل إطار إدارة عناصره؛ لذلك لا يُفعَّل متحكم vanilla فوق شجرة مكونات يديرها React أو Vue أو Angular.

## النصوص واللغة المحلية

لا تحتوي المكونات أي نص خاص بها ولا تختار لغة محلية. يمرر التطبيق كل نص يضعه المكوّن، مثل أسماء العناصر وتسميات أزرار التنقل ورسائل الحالة والتحقق، عبر مدخل يحمل الاسم نفسه في المحوّلات الأربعة، ويمرر `locale` حيث ينسّق المكوّن التواريخ أو الأرقام أو يرتّب النصوص:

```tsx
import { Pagination } from '@hawiyah/react';

export function ResultPages({ page, onPageChange }: { page: number; onPageChange: (page: number) => void }) {
  return <Pagination page={page} totalPages={12} onPageChange={onPageChange}
    label="ترقيم الصفحات" previousLabel="الصفحة السابقة" nextLabel="الصفحة التالية"
    getPageLabel={value => `الصفحة ${value}`}
    getGapLabel={(start, end) => `الصفحات ${start} إلى ${end}`}
    jumpLabel="الانتقال إلى صفحة" goLabel="انتقال" />;
}
```

غياب نص مطلوب خطأ في الأنواع في React وAngular؛ وفي جميع المحوّلات لا يعرض المكوّن شيئًا مكانه ويصدر تحذيرًا واحدًا في بيئة التطوير. يحدد قسم "Text and localisation" في [CONTRACT.md](CONTRACT.md) قواعد النصوص واللغة المحلية، ويسرد دليل كل محوّل مدخلاته، ويربط [سجل التغييرات](CHANGELOG.md) كل نص مدمج سابق بالمدخل الذي حل محله. اضبط `lang` و`dir` على حاوية التطبيق؛ فلا يقرأ أي مكوّن `lang` ولا يضع اتجاهًا افتراضيًا.

## التعديل والتوسعة

عدّل السمة لتغيير المظهر العام، واستخدم الخيارات الموثقة لتغيير مظهر المكون، وركّب المكونات لتلبية احتياجات المنتج. ابدأ من [الكتل القابلة للتحرير](blocks/README.md)، أو شغّل `pnpm new:component request-summary` لإنشاء كتلة يملكها التطبيق داخل `blocks/`. ينشئ الأمر HTML وCSS وإرشادات؛ ولا ينشئ مكون مكتبة جديدًا لكل إطار. التفاصيل في [دليل التوسعة](docs/extension.md).

للمساعدات البرمجية: ابدأ بقراءة [AGENTS.md](AGENTS.md) و[CONTRACT.md](CONTRACT.md) و[EXPANSION.md](EXPANSION.md) و[llms.txt](llms.txt) والفهرس. اعتمد الصادرات الفعلية والأمثلة، وزوّد كل نص مطلوب واللغة المحلية، وحافظ على التسميات والتنقل بلوحة المفاتيح ورسائل الخطأ ودعم الاتجاه عند التعديل.

## حدود النسخة الحالية

يدعم Combobox البحث المحلي واختيار قيمة واحدة، بينما يقدم MultiSelect قائمة مستقلة بمربعات اختيار قابلة للبحث. يرتّب DataTable الصفوف ترتيبًا مستقرًا باللغة المحلية التي يزوّدها التطبيق؛ وتحتاج الجداول الافتراضية أو القابلة للتحرير إلى محرك متخصص. يختار FileUpload وFileDropzone الملفات؛ أما نقلها وتخزينها فمن مسؤولية التطبيق. تجمع أنماط الهاتف وIBAN والهوية البيانات دون إثبات الهوية أو ملكية الحساب. يحدد [دليل التغطية](docs/coverage.md) النطاق، ويوضح [دليل التكاملات](docs/integrations.md) حدود الخرائط والرسوم والمحررات والمصادقة والدفع.

يخزّن Calendar وDatePicker قيمًا ميلادية بصيغة ISO `YYYY-MM-DD`، مع عرض ميلادي أو وفق أم القرى. يعتمد التحويل الهجري على جدول مرجعي مثبت الإصدار بحدود صريحة. راجع [موثوقية التقويم](docs/date-calendars.md) قبل استخدام تاريخ مشتق في سجل رسمي. تستخدم الأمثلة بيانات وهمية وتحاكي إرسال الطلبات وتتبعها.

يعتمد السلوك المشترك على أدوات مستقلة عن العرض ومختزِل صغير لحالة Combobox طُوّرا داخل المشروع، دون الاعتماد على Zag. تُبنى مكتبة Angular بصيغة Angular Package Format، بينما يستخدم مثال Vite وضع JIT عمدًا؛ ولا يثبت المثال تغطية AOT الإنتاجية أو SSR أو hydration. راجع [البنية](docs/architecture.md) و[دليل Angular](packages/angular/README.md).

## الجودة والنشر

الهدف الهندسي للإتاحة هو **WCAG 2.2 AA**، مع فحص لوحة المفاتيح والتقنيات المساعدة والتباين وتقليل الحركة. هذا هدف جودة، وليس إعلانًا بأن جميع الأمثلة اجتازت تدقيقًا كاملًا. تحدد [خريطة الطريق](docs/roadmap.md) بوابات التحقق من الحزم والأطر ورحلات الاستخدام.

يحدد [سجل التحقق](docs/validation.md) النسخة المفحوصة والأوامر ونتائج استهلاك الحزم وحالات السلوك وhydration ورحلات Chromium. يفصل [الفهرس](components.json) التنفيذ عن التحقق لكل مكون؛ ولا تثبت فحوص النسخة السابقة تلقائيًا سلوك الإضافات اللاحقة. لم يُستكمل بعد الاختبار اليدوي بقارئات الشاشة أو التحقق عبر عدة متصفحات.

تتوفر الشفرة في [مستودع هوية](https://github.com/MohamedEmbarak/hawiyah)، ويعرض [الدليل التفاعلي](https://mohamedembarak.github.io/hawiyah/) البدء من المصدر وأمثلة المكونات وسلوكها وواجهاتها البرمجية. يُرخَّص العمل الأصلي بترخيص [Apache 2.0](LICENSE)، وتبقى الخطوط وبيانات التقويم التابعة لأطراف أخرى خاضعة لتراخيصها وإشعاراتها المرفقة. الحزم منشورة على npm تحت النطاق `@hawiyah`؛ يشرح [دليل الإصدارات](docs/publication.md) طريقة بنائها والتحقق منها ونشرها.
